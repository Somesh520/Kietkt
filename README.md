## 🚀 About the Project

Built with modern mobile technologies, BunkBook provides a fast and intuitive interface. The frontend is built using **React Native**, ensuring a smooth, native-like experience on both Android and iOS devices.

### ✨ Key Features
- **Attendance Tracking**: Keep a close eye on your attendance percentage and know exactly when you can safely "bunk" a class.
- **CyberVidya Integration**: Fetches real-time data seamlessly from your KIET CyberVidya portal.
- **Cross-Platform**: Optimized for Android (and ready for iOS).

## 🛠 Tech Stack
- **Frontend Framework**: React Native
- **Navigation**: React Navigation
- **Storage**: AsyncStorage
- **Push Notifications**: Firebase Cloud Messaging (FCM)

## 📂 Project Structure
- `Frontend/CyberVidyaCLI/`: Contains the complete React Native source code for the mobile application.
- `update.json`: Contains the metadata for the latest Over-The-Air (OTA) updates and release versions.
